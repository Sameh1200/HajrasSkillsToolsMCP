# HajrasSkillsToolsMCP

Organized skill packs for bug bounty / recon tooling.

## Structure

```
skills/
├── nmap/skill.md
├── subfinder/skill.md
├── httpx/skill.md
├── nuclei/skill.md
├── amass/skill.md
├── ffuf/skill.md
├── sqlmap/skill.md
├── katana/skill.md
├── dnsx/skill.md
├── naabu/skill.md
├── gau/skill.md
├── masscan/skill.md
├── dirsearch/skill.md
├── nikto/skill.md
└── burpsuite/skill.md
```

Main branch keeps a single top-level `skills/` directory so future tool packs stay organized.

## Each skill.md contains

- Repo
- Installation
- Using
- **Real-time usage (typical)** — duration tables from practical recon workloads
- Current Step
- Next Step
- Errors Fixes
